## 启动与运行

### Q: 双击 `start.bat` 窗口一闪就没了

说明启动过程中出错并立即退出了。**改成从命令行运行**，报错就会留在屏幕上：

```bat
cd /d 项目目录
start.bat
```

常见原因是没装 Node.js，或 Node 版本太低（需要 22+）。

### Q: 提示 `Cannot use import statement outside a module`

Node 版本太低。本项目的 `.js` / `.mjs` 都用 ESM 写法但**没有 `package.json`**，
依赖 Node 22+ 的语法自动探测。升级到 22 LTS 或更高即可：[nodejs.org](https://nodejs.org/)

用 `node -v` 查看当前版本。

### Q: 端口 8787 被占用（`EADDRINUSE`）

换个端口启动：

```bash
# Windows (cmd)
set PORT=9000 && node local-server.js

# Windows (PowerShell)
$env:PORT=9000; node local-server.js

# Linux / macOS
PORT=9000 node local-server.js
```

> ⚠️ **`PORT` 写在 `.env.local` 里是不生效的**——`.env.local` 解析器只认
> `CLINE_REFRESH_TOKEN` 和 `API_KEY` 两个键。必须像上面这样通过环境变量传。

或者先找出占用端口的进程杀掉：

```bash
# Windows
netstat -ano | findstr :8787     # 最后一列是 PID
taskkill /F /PID <PID>

# Linux / macOS
lsof -i :8787
kill -9 <PID>
```

### Q: 服务启动了，但页面打不开

确认两个都装了：进程还在跑（终端窗口没关），以及地址是 `http://localhost:8787`
（不是 `https`）。

`localhost` 和 `127.0.0.1` 都可以。如果都不行，试试 `/v1/health`：

```bash
curl http://localhost:8787/v1/health
```

有 JSON 返回说明服务是好的，问题在浏览器。

### Q: 改了代码怎么生效？

`worker.js` 支持**热重载**——改完保存，下一次请求会自动加载新版（终端会打印
`[hot-reload]`）。注意：

- 改 `console.src.html` **不会**自动生效，必须先跑 `node build-console.mjs`
  把它注入 `worker.js`，热重载才会看到变化。
- 改 `.env.local` 也不用重启，配置是每次请求重新读的。
- 改 `local-server.js` 本身**需要重启**。
- 热重载会重置内存状态：登录得到的临时账号、模型缓存都会丢，需要重新登录。

## 中文乱码

### Q: Windows 下中文显示成乱码

Windows 控制台的默认代码页是 **936（GBK）**，而本项目输出的是 **UTF-8**。

**用启动脚本不会有这个问题**（它们会先执行 `chcp 65001`）。
如果坚持手动运行，先切代码页：

```bat
chcp 65001
node local-server.js
```

### Q: 我改了 `start.bat`，结果报一堆「不是内部或外部命令」

`cmd.exe` 解析批处理文件时有两个坑，改这个文件必须避开：

1. **不能有非 ASCII 字符在 `chcp 65001` 之前**。cmd 按「当前代码页」逐行解码，
   中文写在 `chcp` 之前会被错误解码；更麻烦的是**多字节字符位于行尾时，
   cmd 会算错字节偏移，把一行拆成两条命令**（实测中文字符串结尾的 `rem` 注释必触发）。
2. **行尾必须是 CRLF**，cmd 不认 LF 行尾的 `.bat`。

正因如此，`start.bat` 里只保留纯 ASCII 的引导代码，**所有中文提示都在 `start.mjs`**。
要加中文提示，请加到 `start.mjs` 里。

行尾要求已由 `.gitattributes` 固定，不用手动处理。

## 调用报错

### Q: 401 Unauthorized

三种可能，控制台会给出对应的提示：

| 返回的 `reason` | 含义 | 怎么办 |
|---|---|---|
| `server_no_key` | 服务端没配 `API_KEY` | 本地一般不会遇到（会自动生成）。检查 `.env.local` 里 `API_KEY` 是否被清空了 |
| `missing_client_key` | 请求没带密钥 | 加上 `Authorization: Bearer <你的API_KEY>` |
| `wrong_client_key` | 密钥不对 | 核对密钥。控制台「接入配置」页可以直接复制 |

> 💡 本地运行时 `API_KEY` 会自动生成并写进 `.env.local`，同时注入控制台页面，
> 所以用控制台不用手填。用第三方客户端时才需要手动填。

### Q: 500 `缺少 CLINE_REFRESH_TOKEN 环境变量`

`.env.local` 里的 `CLINE_REFRESH_TOKEN` 是空的（或没这一行）。

两种解决办法：

- 在控制台「账号」页点「登录新账号」，登录后立即可用
  （**本地运行会自动存盘，重启不丢**；云端没有可写磁盘，重启或重新部署会消失）
- 跑 `python cline_oauth.py` 拿到 token，它会自动写进 `.env.local`（永久生效）

### Q: 402 `insufficient_credits`

用了付费档模型且余额不足。**换免费模型**：

- ✅ `cline-free/deepseek-v4.1-flash`（默认）
- ✅ `deepseek/deepseek-v4-flash`
- ❌ `deepseek/deepseek-v4.1-flash`（注意：这个**不带** `cline-free/` 前缀，是付费档）

前缀差别很关键，见下文「模型相关」。

### Q: 429 `Daily free limit reached`

**不是 bug**，是这个账号的**每日免费额度**用完了。上游 Cline 对免费模型有日配额，
响应里会带恢复时间（如 `Try again in 2h 51m`），等冷却结束自动恢复。

想立刻继续用，加更多账号即可（见下文）。

### Q: 请求报 `1010` 或连接被拒

`1010` 是 **Cloudflare 网关**的拦截，**本地运行不会遇到**。
如果你是在调云端部署的地址，见 [部署到云端.md](./部署到云端.md)。

## 账号与额度

### Q: 怎么加第二个账号？额度用完了想自动切号

线上环境：在 `CLINE_REFRESH_TOKEN` 里一行填一个 token 即可，会自动轮询和切号。

> ⚠️ **但本地 `.env.local` 文件不支持多账号。** 解析器是逐行读 `key=value` 的，
> 遇到没有 `=` 的行会直接跳过，所以第二个裸 token 行会被丢弃，
> 最终只有最后一个 `CLINE_REFRESH_TOKEN=` 生效。
>
> 本地要多账号，除了真多行的环境变量（`start.mjs` 会把环境变量透传给服务），
> **更省事的办法是在控制台「账号」页逐个登录**——登录的账号立即进池、参与轮询和切号，
> 而且本地运行时会自动存盘（写在 `~/.ClineFreePool-state.local.json`），重启不丢。

### Q: 控制台登录的账号，重启后不见了

分两种情况：

**本地运行（`start.bat` / `node start.mjs`）** —— 账号会自动存盘，重启不丢。
存盘文件是 `~/.ClineFreePool-state.local.json`（用户主目录，权限 0600，不在项目目录里）。

> 这个文件里含 refreshToken。想换机器或手工备份时，用控制台「账号」页的
> **详情 → 显示完整值** 取 token，比直接拷文件干净。

**部署到云端（Cloudflare Workers / Vercel）** —— 没有可写磁盘，账号只活在那一次实例里，
重启或重新部署就消失。这是刻意的取舍，为了保住「单文件复制粘贴即可部署」。

要长期保留：登录成功后控制台会把 refreshToken 显示出来（带复制按钮），
把它填成部署环境的 `CLINE_REFRESH_TOKEN` 变量即可。

### Q: 除了本地两种方式，还有别的获取途径吗？

有，仓库里还带了一个 **GitHub Actions 工作流** `.github/workflows/get-token.yml`，
适合**手边没有电脑、只有手机**的场景。

它把授权流程放在 GitHub 云端跑，用 Telegram 接收结果：

1. 把本项目推到你的 GitHub 仓库（或 fork）
2. 在仓库 **Settings → Secrets and variables → Actions** 添加两个 secret：
   - `TG_BOT_TOKEN`：你的 Telegram Bot token
   - `TG_CHAT_ID`：接收消息的 chat_id
   > 缺任一个，工作流会直接报错退出，不进入授权流程。
3. 进 **Actions** 页 → 左侧选「获取 Cline refreshToken」→ **Run workflow**
4. Telegram 会收到**授权链接 + 设备码**，手机浏览器打开登录授权
5. 授权成功后 TG 收到 `refreshToken`，复制填进 `.env.local` 即可

> 🔒 refreshToken 与账号邮箱都**不会出现在 Actions 日志**里
> （`::add-mask::` 打码 + 只推 TG）。工作流跑完会自动清理旧运行记录，只保留最新 1 条。

注意这种方式**需要联网的 GitHub 仓库**，和本地运行无关，只是拿 token 的另一种途径。

### Q: 账号显示「冷却中」或「部分冷却」

上游按**账号 + 模型**组合独立计额，所以冷却也是这个粒度：

- **部分冷却**：该账号有模型到了上限，但**其它模型照常可用**。
  悬浮账号卡片能看到是哪个模型、什么原因、还剩多久。
- **冷却中**：该账号的模型全部在冷却里。

冷却原因与时长解析自上游响应：

| 原因 | 说明 | 恢复时间 |
|---|---|---|
| 免费日额度 | 免费模型的每日配额用尽 | 上游给的时间，否则**次日本地零点** |
| 订阅额度 | ClinePass 额度用尽 | 上游给的时间；通常不说，退回兜底时长 |
| 花费上限 | 账户达到周期花费上限 | 上游 JSON 里的 `resets_at` |
| 未识别 | 上游改了文案 | 兜底时长（默认 30 分钟，可在「设置」页改） |
| 空响应 | 上游返回 200 但内容全空 | 30 秒 |

冷却期间请求会自动用其它账号（或同账号的其它模型）。

> 💡 **猜错了不用干等**：冷却时长有一部分是我们按 429 猜的。
> 到「账号」页点该账号的**详情**，可以**单独解除某个模型的冷却**。

### Q: 为什么全部账号都可用，却返回 429

看响应里的 `error.model` 与提示文字——那是**该模型**在所有账号上都冷却了，
不是账号本身不可用。换个模型通常就能继续用，或者等冷却结束。

### Q: refreshToken 会过期吗？

会，但有效期较长。如果请求返回 401 / 403，重新获取一个即可
（`python cline_oauth.py`，或在控制台重新登录）。

> ⚠️ **上游会在每次刷新 token 时轮换 refreshToken。** 本项目会自动把新值存下来：
> - 控制台登录的账号 → 自动落盘，不用管。
> - **环境变量里的账号 → 新值没法写回环境变量**，所以重启后会拿着旧的那把死钥匙，
>   表现为「重启后所有请求都失败」。
>
> 遇到这种情况：到「账号」页点该账号的**详情**，页面会标出「已被上游轮换过」，
> 点**显示完整值**复制新 token，更新你的 `CLINE_REFRESH_TOKEN` 或 `.env.local`。
> 日志里也会有对应提示。

## 模型相关

### Q: 该用哪个模型？

默认填 `cline-free/deepseek-v4.1-flash`，它是免费的。

`GET /v1/models` 返回的是**你在控制台「模型」页启用过的**模型。全新实例还没启用过任何模型时，
会**实时向上游取当前的免费模型清单**，所以不会拿到空列表。

### Q: `cline-free/deepseek-v4.1-flash` 和 `deepseek/deepseek-v4.1-flash` 有什么区别？

**前缀决定走哪条通道，差别很关键：**

| 模型 ID | 通道 |
|---|---|
| `cline-free/deepseek-v4.1-flash` | ✅ 官方免费额度，无需 credits |
| `deepseek/deepseek-v4.1-flash` | ❌ 付费档，余额不足直接 402 |

注意 `deepseek/deepseek-v4-flash`（**没有** `.1`，也没有 `cline-free/` 前缀）
是另一个模型，它是免费的——和上面那个付费的 `deepseek/deepseek-v4.1-flash` 不是同一个。

### Q: 模型列表为什么这么短？上游明明有几百个模型

因为 `GET /v1/models` **只返回你在控制台「模型」页启用过的模型**（一个都没启用时实时取上游当前的免费清单）。

上游有四百多个模型，全列给客户端的结果是每次选模型都要翻四百多项、其中大半还会直接 402/403。
所以由你挑：在「模型」页点分组标题的「全部添加」整组加入，或点单张卡片的 ＋ 逐个加。

> 💡 **这是"发现过滤器"，不是访问控制。** chat 端点不校验模型是否在启用列表里 ——
> 你在客户端里写死一个没在面板加过的模型 ID，照样能用。
> 面板只决定客户端**能看到什么**，不决定**什么能用**。

### Q: 怎么知道某个模型现在还能不能用？

在「模型」页点卡片上的「检测」。它会发一次最短的真实请求（`Reply with only OK.`），
告诉你结果和耗时。

它会**校验正文内容**，而不是只看 HTTP 状态码——上游有时返回 200 但内容全空，
那种在实际使用中等价于不可用。

失败时给的是能照做的原因，不是 HTTP 码：

| 提示 | 该做什么 |
|---|---|
| 当前账号额度或订阅不足 | 换免费模型，或到「账号」页看余额 |
| 模型或可用渠道不存在 | 上游可能已下架该模型 |
| 当前账号认证失败或无权访问 | 到「账号」页重新登录 |
| 当前账号或模型受到限流 | 等冷却，或加账号 |
| 未获得有效文本回答 | 上游异常或输出预算不足，重试通常即可 |

> ⚠️ 检测会真实消耗一点额度。另外同一模型重复点会共享同一次检测，不会重复打上游。

### Q: 「全部模型」区块怎么是空的？

它是**折叠**的，点一下标题才会去抓 —— 上游那份清单有四百多条、约 500 KB，
没必要在打开页面时就一起拉下来。抓到后服务端会缓存 30 分钟。

展开后可以搜名称或 ID（如 `qwen`、`flash`），搜索只过滤本地已有数据，不发请求。

### Q: 移除模型后客户端还能调用它吗？

能。移除只是让它从 `/v1/models` 里消失（客户端不再"看到"它），
并不阻止调用——见上面关于「发现过滤器」的说明。

### Q: 默认模型只能从已启用的模型里选吗？

对。默认模型是"不带 `model` 的请求打哪个"，指向一个没启用的模型会让面板显示与真实行为脱节，
所以服务端会拒绝。先把模型加到「已启用」，再设默认。

### Q: 我配置的 `max_tokens` 好像没生效

对，这是**故意忽略**的。上游对带 `max_tokens` 的请求一律返回
500 `{"error":"empty response content"}`，所以 worker 构造请求时不注入该字段
（客户端传了也丢弃）。

代价是客户端无法用 `max_tokens` 提前截断输出，由上游按自己节奏生成。

## 安全与隐私

### Q: 谁能看到我的 refreshToken？

只有你。

- **本地**：存在 `.env.local` 里，该文件已在 `.gitignore` 中（`*.local` 规则），不会被提交
- **云端**：存在 CF Workers / Vercel 的**机密变量**里（加密存储，代码里看不到、日志里不显示）

不要把真实 refreshToken 写进 `wrangler.toml` 等会提交的文件。

### Q: 控制台的数据会上传吗？

不会。密钥、对话历史、日志、测速结果都只存在**本机浏览器的 localStorage**，不上传别处。

控制台是**单文件自包含**的，不引用任何外部 JS/CSS，内网或离线环境也能正常打开。

### Q: 本地服务会暴露到局域网吗？

**默认不会**。`local-server.js` 默认只绑 `127.0.0.1`（仅本机可访问），启动时会打印
「（仅本机可访问）」确认这一点。

这是刻意的默认值：控制台页面会把 `API_KEY` 注入进去，而这个服务把自己登录过的账号额度
开放给任何能访问它的人。绑所有网卡等于把钥匙连同门一起送给同网段的人。

确实要让别的机器连（比如手机）时显式放开：

```bash
# Windows (cmd)
set HOST=0.0.0.0 && node local-server.js
# Linux / macOS
HOST=0.0.0.0 node local-server.js
```

放开后请确保在可信网络里，并注意同网段的人打开控制台就能拿到你的 API Key。
（要更严的隔离，就只在需要时开，用完关掉。）

### Q: 免费额度够用吗？

`cline-free/deepseek-v4.1-flash`（默认）、`deepseek/deepseek-v4-flash`、
`poolside/laguna-s-2.1:free`、`z-ai/glm-5.3-flash` 都是免费模型。

免费模型有**每日额度**（用尽返回 429，数小时后恢复）。多账号可缓解。

`zai/glm-5.2` 是付费模型（约 $0.0008/次），走 Cline 系统凭证，无每日额度限制。
